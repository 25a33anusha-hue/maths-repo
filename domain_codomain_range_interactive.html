1. Learn the concepts

For a function f : A → B, set A is the input set and set B is the declared output set.

Domain

The domain is the set of all permitted input values for a function.

In f : A → B, the domain is A.

Codomain

The codomain is the set of possible outputs declared for the function. Some codomain elements may never be reached.

In f : A → B, the codomain is B.

Range (image)

The range is the set of output values that the function actually produces from the domain.

The range is always a subset of the codomain.

Function rule

A relation is a function when every element of the domain is assigned exactly one output in the codomain.

Range(f) ⊆ Codomain(f)

Different inputs are allowed to map to the same output.

3. Worked examples

Example A · Squaring

Let A = {1, 2, 3}, B = {1, 2, 4, 9}. If f(x) = x², then the outputs are 1, 4, 9.

Domain: {1, 2, 3}
Codomain: {1, 2, 4, 9}
Range: {1, 4, 9}

Example B · Doubling

Let A = {0, 1, 2, 3}, B = {0, 2, 4, 6, 8}. If f(x) = 2x, every domain value maps to an even number.

Domain: {0, 1, 2, 3}
Codomain: {0, 2, 4, 6, 8}
Range: {0, 2, 4, 6}

Example C · Same range, different codomain

Let A = {1, 2, 3}, f(x) = x + 1. If B = {2, 3, 4, 5, 6}, the range is still {2, 3, 4}; 5 and 6 are not reached.

Key idea: The codomain is specified; the range is calculated.
